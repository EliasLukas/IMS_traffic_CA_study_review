# Experiments Guide

This file documents experiment execution for the current repository layout.

## Project structure

From repository root:

- `src/` – simulator source code (`main.cpp`, simulation logic, data gathering)
- `run.sh` – experiment presets for paper figures
- `Makefile` – build entry point (`ims_traffic` binary)
- `data/csv/` and `data/plots/` – data/plot storage directories
- `csv/` – generated by `run.sh` at runtime (preset outputs)

## Build

Build from repository root:

```bash
make
```

This produces:

- `./ims_traffic`

## Running experiments

Use the preset runner:

```bash
bash run.sh --figure <preset> [options]
```

Main presets:

- `f1` – Figure 1 (symmetric, `switch-prob=1.0`)
- `f2` – Figure 2 (asymmetric, `switch-prob=1.0`)
- `f3` – Figure 3 (symmetric + asymmetric comparison)
- `f4` – Figure 4 (symmetric + asymmetric + single-lane)
- `f5` – Figure 5 (`switch-prob` in `{0.5, 1.0}` for both policies)
- `f6` – Figure 6 (normalized lane-change metric inputs)
- `f7` – Figure 7 (`switch-prob` sweep for symmetric/asymmetric)
- `f10` – Figure 10 (look-distance related comparison)
- `f11` – Figure 11 (`lookback-zero` variants)
- `all` – runs all core presets

Extra single-scenario presets:

- `sym_p1`, `asym_p1`, `sym_p05`, `asym_p05`
- `single_road`
- `sym_lb0_p1`, `asym_lb0_p1`

### Common options

- `--density-range <min> <max> <step>`
- `--loops <N>`
- `--ticks <N>`
- `--road-length <N>`
- `--max-velocity <N>`
- `--slowdown-prob <F>`
- `--dry-run`

## Outputs

- Preset runs write CSV files into `csv/` in repository root.
- Position-time visual data is produced by simulator option `--position-time-data 1`.
- For direct simulator runs, available key flags include:
  - `--symmetric 0|1`
  - `--switch-prob <0..1>`
  - `--lookback-zero 0|1`
  - `--lane-count <N>`
  - `--csv-output 0|1`

## Example commands

Figure 1 at single density:

```bash
bash run.sh --figure f1 --density-range 0.09 0.09 0.01 --loops 1
```

Figure 3 sweep:

```bash
bash run.sh --figure f3 --density-range 0.10 0.50 0.02
```

Direct simulator run (symmetric, position-time data):

```bash
./ims_traffic --position-time-data 1 --road-length 12000 --ticks 1400 --max-velocity 5 --density 0.09 --slowdown-prob 0.5 --symmetric 1
```
